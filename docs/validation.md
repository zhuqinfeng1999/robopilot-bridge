# 🧪 验证范围

| 层次 | 如何验证 | 本仓库提供的证据 |
|---|---|---|
| 本地闭环 | `python -m unittest -v` | 通过 stdio 完成 MCP 握手、工具发现、含 PNG 的观测、五次动作和目标判定；检查旧 revision、关闭会话和三份配置格式 |
| 客户端协议 | 离线输入预设的客户端消息 | 检查 Codex 和 Antigravity 的成功、失败和流结束，检查 Cursor ACP 握手、交错权限请求和错误返回 |
| 官方客户端接入 | 使用自己的登录启动一次模拟并检查 `events.jsonl` | 提供三种启动入口。发布验证未调用在线模型。具体可用模型、工程信任设置和计费取决于本机版本与订阅 |
| 原研究系统 | 同一设备上的独立实验会话、双相机观测、控制器反馈及人工判定 | 文档归纳三家接入方式。公开示例是重新实现的教学版本，不包含原实验数据 |
| 新设备 | 回放、仿真、只读观测，再做受监督的单技能实验 | 机械臂、人形和灵巧手移植指南。实际设备需自己的驱动与验收 |

`pilot.py check` 只检验本地模拟器的终态。它适合工程冒烟测试；做对抗性评测时，把可信执行端与判定日志置于模型无法读写的位置。本示例生成的工作目录、CLI 的额外工具与账号配置不构成对抗性沙箱。
