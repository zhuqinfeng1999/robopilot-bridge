# 🦾 从四格模拟器到真实设备

[首页](../README.md) · [客户端接入](providers.md) · [实验经验](field-notes.md)

把工具的**语义**稳定下来，规划器可以复用，底层驱动交给每台设备自己的执行端。公开模拟器把一格移动定义为一个已完成动作，每次执行都产生一个新 revision。这个约定使迟到的重复指令可被识别。

| 场景 | 适合作为观测的量 | 一个有明确结束条件的技能 | 由本地执行端确认 |
|---|---|---|---|
| 桌面机械臂 | 双视角 RGB-D、坐标系、TCP 位姿、夹爪开度 | 移到已验证放置点并释放积木 | 控制器完成反馈、持物状态、释放后的观测 |
| 人形机器人 | 基座姿态、支撑脚、关节状态、目标物体与时间戳 | 在原地站稳时伸手触碰面板 | 平衡控制器、接触与支撑状态、技能结束或中止 |
| 灵巧手 | 腕部观测、关节位置、指尖接触 | 采用设备支持的预抓姿态夹持泡沫块 | 力和关节约束、接触稳定性、滑移 |
| 仿真或回放 | 同一格式的图像与状态、仿真步与种子 | 对应的仿真技能或只读观测 | 仿真物体状态，回放时使用原始观测 |

## 工具合约

- **observe** 返回 `episode_id`、`observation_id`、采集时间、状态及图像；多相机记录视角名、单位、坐标系、深度有效性。每次改变图像缩放或拼图布局都要同时描述像素坐标变换。
- **act** 接受技能名、规范化参数、观测版本和唯一命令 ID。设备端验证输入并接管本地控制循环。返回 accepted / running / completed / failed 中可证实的状态，附执行后观测。指令发出后连接断开，先按命令 ID 对账再决定是否重试。
- **finish** 返回规划器的结束状态。另存控制器状态、物体结果和操作者判定。仿真测试可让独立状态断言判分，物理实验可用双视角录像人工判定。

伺服、平衡、限位、急停和故障恢复属于现场控制器。首次接入只读状态和回放，然后用设备自己的调试流程验证一个可中止的低风险技能。确保断连后动作有明确归宿，再开放多步任务。

## 基线与安全审核

基线和审核方法共享任务、起始状态、观测与技能语义，各自使用独立会话。审核器在本地执行端插入，返回允许、阻止或需要新观测。遇到阻止时将可见状态返回规划器，让它在允许的技能范围内重新规划。人工标签、私有场景布置和其他轮次的轨迹只进入操作者侧。明确记录超时、拒绝、任务完成和评审判定，便于解释差异。

## 最小接入验收

在自己的平台逐项复现：一次新观测能被当前模型正确读取；一次技能得到可验证的反馈；旧 revision 被拒绝；相同命令重发只能产生一次物理作用；停止后没有遗留动作；重开实验时看不到前一轮的私有标签。模拟器实现版本检查，生产执行端需要额外实现持久命令去重和失联恢复。
