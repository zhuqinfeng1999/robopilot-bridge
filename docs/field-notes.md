# ⏱ 图像、延迟与可复现性

[首页](../README.md) · [三条接入路线](providers.md)

**同一次机械臂动作耗时相近，总时长仍可能差很多。** 给每个工具调用串起六个单调时钟时间点：提交任务、客户端首个事件、收到工具请求、控制器反馈完成、工具结果送回、下一次模型事件。跨进程或机器另存 UTC 用于对照；网络或模型的归因还需要端侧证据。

| 观察到的现象 | 优先比对 | 研究项目采用的处理 |
|---|---|---|
| 启动慢，机器人还没动 | 登录、工作区扫描、记忆读取、首个模型事件 | 每次实验创建干净工作区，只暴露本轮工具与共用的必要背景 |
| 每次动作后读多张图 | 工具返回的图像数量、大小、是否是拼图的重复切片 | 只传一份足够判读的观测，本地保留原图；缩放后显式换算坐标 |
| Antigravity 多出 view_file | MCP image 是否已可见、是否被客户端转成文件、额外模型轮次 | 只在图像不可见或细节不足时读取已登记的本轮图像，核对像素哈希 |
| Cursor 调用间有长空档 | ACP 消息到达、图像载荷、首字节、代理、服务暂停 | 记录请求与响应窗，批量查询相邻深度点，复用本轮会话 |
| 执行了动作却收到错误 | 工具反馈、CLI 终态、供应商错误、断流位置 | 结合物理反馈和传输结果归档，避免重复执行或将错误计作成功 |
| 双相机画面中断 | 同步误差、有效帧对和录像覆盖时段 | 按时间戳记录缺帧，保留原判定与录像完整性两个字段 |

在同一设备、起点、任务、共享示例、速度与工具协议上比较。为每个 provider 记录 CLI 版本、请求模型、实际报告模型、推理强度以及可见服务档。未暴露服务档时填 unknown。单轮时间只代表这次运行；代理选择、网络、模型思考与图像处理可能同时影响总耗时。

公开日志只需工具名、动作参数、状态、时间、图像摘要及最终结果。可发布的示例图用合成数据。本仓库模拟运行的事件仅写入本机生成的目录。
